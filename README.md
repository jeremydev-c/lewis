# 🎃 Lewis Turns 19 • Halloween Birthday Bash

Official Halloween party invitation and real-time RSVP website as **Lewis turns 19** in Thika, Kenya on **Saturday, 31st October 2026**.

## 🦇 Features

- **Atmospheric Visuals & Soundscape**: Dark theme with rich neon accents, floating mist/embers canvas, and synthesized Web Audio ambient sound effects.
- **Live Countdown Timer**: Ticking down to October 31st at 6:30 PM (East Africa Time).
- **Party Intel & Dress Code**: Clear guidelines on venue, time, and mandatory Halloween costumes.
- **Interactive RSVP Portal**:
  - Simple *Will You Attend?* selection (`Hell Yes, I'll Be There!` vs `Sorry, Can't Make It`).
  - Collects guest name, WhatsApp contact, costume idea, +1s, and a personal birthday wish.
  - Direct **"Notify Lewis on WhatsApp"** button generating a pre-filled confirmation text.
- **Live Client Dashboard**:
  - Real-time guestlist and response metrics (Total, Attending, Declined, Plus Ones) visible to Lewis.
  - Filter by *All*, *Attending*, or *Declined*.
  - Delete action per row to manage duplicate entries.
- **Calendar Download**: 1-click `.ics` file download for Google Calendar, Apple Calendar, and Outlook.
- **100% Mobile Responsive**: Optimized for seamless navigation and touch targets on all phone screens.
- **Zero Dependencies**: Pure HTML5, Vanilla CSS, and JavaScript. No build tools or server setup required.

## 🚀 Live Deployment

To deploy via **GitHub Pages**:
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Branch**, select `main` branch and `/ (root)` folder.
3. Click **Save**. Your site will be live in seconds!
